# Online-Bookstore-SQL-Project

## 📌 Project Overview
This project demonstrates the design and analysis of an **Online Bookstore Database** using SQL.  
The database stores information about **Books, Customers, and Orders** and allows meaningful data analysis through SQL queries.

## 🛠 Tools & Technologies
- PostgreSQL
- SQL
- CSV Data Import

## 🗂 Database Structure

### 📘 Books Table
- Book_ID (Primary Key)
- Title
- Author
- Genre
- Published_Year
- Price
- Stock

### 👤 Customers Table
- Customer_ID (Primary Key)
- Name
- Email
- Phone
- City
- Country

### 🛒 Orders Table
- Order_ID (Primary Key)
- Customer_ID (Foreign Key)
- Book_ID (Foreign Key)
- Order_Date
- Quantity
- Total_Amount

## 🔑 SQL Concepts Used
- Database & Table Creation
- Primary & Foreign Keys
- CRUD Operations
- WHERE, ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- GROUP BY & HAVING
- JOINS (INNER, LEFT)
- Data Analysis Queries

## 📊 Sample Analysis Queries
- Retrieve books by genre
- Find the most expensive book
- Calculate total revenue
- Identify frequent customers
- Analyze book sales by genre
- Calculate remaining stock after orders

## 📈 Key Learnings
- Designing relational databases
- Writing optimized SQL queries
- Performing real-world data analysis
- Understanding customer and sales behavior

## ✅ Conclusion
This project showcases hands-on SQL skills required for a **Data Analyst Fresher** role and demonstrates practical database management and analysis.
